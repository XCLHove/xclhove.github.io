个人项目 ​

XNote ​

XNote 是一个开源 Web 端的 Markdown 笔记管理应用，支持在线编辑和预览 Markdown 笔记。

  • 线上演示：XNote
  • 仓库地址（后端）：xnote-springboot(Github) | xnote-springboot(gitee)
  • 仓库地址（前端）：xnote-nuxt(Github) | xnote-nuxt(gitee)

X-RPC ​

使用 Java 开发的 RPC 框架，开发者可以引入Spring Boot Starter，通过注解和配置文件快速使用框架，像调用本地方法一样轻松调用远程服务；支持动态扩展传输协议、序列化 器、负载均衡器、重试和容错策略等。

  • 仓库地址：x-rpc(Github) | x-rpc(gitee)

Github Proxy ​

使用多种方式搭建 github 镜像站，用于解决 github 访问速度慢的问题。

  • 线上地址：github proxy
  • 仓库地址：github proxy(Github) | github proxy(gitee)

EA WRC Club Manager ​

使用 EA Racenet 的 api，将 EA Racenet 中 EA SPORTS™ WRC 部分功能的前端页面进行重写以实现本地加载页面以提高加载速度的跨平台桌面应用，基于 Electron + Vue3 实现。

  • 仓库地址：EA WRC Club Manager(Github) | EA WRC Club Manager(gitee)

Network Speed ​

在Linux系统通过悬浮窗显示实时网速的小工具，基于 Java AWT 和 ifstat 实现。

  • 仓库地址：network speed(Github) | network speed(gitee)
